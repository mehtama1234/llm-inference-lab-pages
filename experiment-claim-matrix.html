claim discipline

A run is useful only when the claim is narrower than the evidence.

The same output file can support a mechanism claim, a workflow claim, a fit claim, a quality claim, or a speed claim. Those are different claims. Mixing them is how experiments become misleading.

experiment report = question + changed variable + constants held fixed + measured object + artifact evidence + allowed claim + locked claim + next gate
Mechanism proofExplains why a method changes computation, bytes, waiting, or trainable parameters.
Workflow proofShows a script, notebook, archive, reload, or handoff path ran end to end.
Benchmark proofCompares measured runtime behavior under controlled same-workload conditions.
