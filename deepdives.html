Interactive Lab 3: Layers Change Token Vectors

A layer receives a tensor shaped as batch, token positions, and hidden size. It returns the same outer shape. The shape stays stable because the next layer expects the same kind of tensor, but the numbers inside each token vector change.

One block, step by step

input batch x tokens x hidden 1 x 5 x 32
layer norm rescales each token vector 1 x 5 x 32
Q K V three projected views 1 x 2 x 5 x 16
scores each query position scores key positions 1 x 2 x 5 x 5
merge heads head outputs become one tensor 1 x 5 x 32
MLP expand then shrink each token vector 1 x 5 x 128 to 1 x 5 x 32
output same shape, changed values 1 x 5 x 32
Attention lets each token position compute from earlier token positions.
The MLP changes each token vector after attention has mixed position information.
Residual add means the block adds a computed change back to the incoming tensor.
The output shape stays stable so the next block can read it without reshaping the whole model.

Interactive Lab 8: VRAM Budget And Precision

VRAM is the memory on the GPU. During inference, the countable parts are model weights, KV cache, and activations. Precision changes how many bytes each number uses. Temporary buffers and runtime reserve are also real memory, but they are not fixed by the simple formulas.

Temporary buffers and runtime reserve are extra memory used by PyTorch, CUDA, and kernels while work is being scheduled and executed.

Interactive Lab 10: Matmul And Dispatch

Most GPT layer work is matrix multiplication. A matrix multiply takes rows from the left tensor and columns from the right tensor. The shared dimension is the count each output number must multiply across. GPUs run this work through kernels. A kernel is one launched operation on the device.
