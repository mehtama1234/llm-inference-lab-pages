cross-experiment lessons

The whole lab reduces to five recurring questions.

For every inference experiment, ask: 1. What token sequence is being served? 2. What bytes must fit and move? 3. What work is prefill, decode, queue, or overhead? 4. What function changed: base model, adapter, runtime, scheduler, or deployment surface? 5. What claim is allowed by this exact evidence?
Mechanism firstThe math page should predict which metric moves before the run starts.
Evidence secondThe result page should say whether that metric moved under fixed conditions.
Claim thirdThe public writeup should name the allowed claim and the locked non-claim.
Capstone lastThe production decision waits for the host proof because that is the first surface that can compare TGI and vLLM fairly.
