Hugging Face settings map

How to read inference settings without guessing

Every setting belongs to a specific part of the system. Some settings change model loading, some change generation, and some only exist in a serving runtime such as TGI.

First Rule: Place The Setting Before Reading It

A setting is easier to understand after you place it in the system. Ask what it changes: model loading, generation, cache, attention, scheduling, memory placement, or streaming service behavior.

loadweights, dtype, device placement, offload
generatenew-token limit, cache choice, sampling settings
executeattention path, compile path, device kernels
serverouter, queue, batch limits, stream metrics

Settings Map

The same word can be misleading if you read it in the wrong layer. `Transformers` runs model code in Python. `TGI` is a serving system around model workers. A library setting and a serving setting can both affect latency, but they do it through different parts.

Setting to mechanism

max_new_tokensgenerate()Stops decode after this many new output tokens.
use_cachegenerate()Turns KV cache on or off during decode.
cache_implementationgenerate()Selects the cache class, such as dynamic, static, offloaded, or quantized.
dtypeloadChanges bytes per parameter number.
device_maploadPlaces modules on CPU, GPU, disk, or a split map.
attn_implementationloadSelects the attention implementation supported by the model and hardware.
compileexecuteReuses a compiled graph when shapes stay stable.
TGI batch limitsserveControls waiting requests, prefill token budget, and total batch token budget.
offloadload/cacheMoves weights or cache away from GPU memory when needed.

`torch_dtype` appears in older examples; current Transformers model loading docs use `dtype` while still discussing `torch_dtype` metadata in model config.
`max_new_tokens` counts only generated tokens, not prompt tokens.
Static cache can help compile decode, but it reserves memory for a fixed maximum size.
TGI batching settings belong to the router and scheduler, not to `AutoModelForCausalLM.generate()`.

Official Docs Used

TGI launcher docs: batch token limits, waiting ratio, and queue-related serving settings.
