public static audit

The public site is an HTML report, not the raw experiment repository.

The public Pages repo intentionally publishes only .html, styles.css, and .nojekyll. This page tells readers which pages are standalone public evidence, which older pages are local dashboards that expect private JSON artifacts, and how to read the site without confusing a missing raw file for a missing experiment.

publish policy

Raw artifacts stay private; public pages carry the interpreted evidence.

The private lab has scripts, JSON results, archives, checksums, notebooks, host bundles, and return packets. The public site is the readable report layer. That separation is deliberate: the public pages should teach the math, describe the experiment, show the allowed claim, and state the non-claim without exposing raw operational files.
