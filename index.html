Foundation

Why These Concepts Matter

The user sees delay, price, and reliability. These come from a few concrete limits: number of arithmetic operations, bytes stored in VRAM, bytes moved from memory, and requests waiting for service.

Matmul affects compute time

More layers, larger hidden size, and more tokens increase multiply-add work.

VRAM affects what fits

Weights, activations, and KV cache must fit on the device or be moved slower.

Precision affects bytes

16-bit uses two bytes per number. 8-bit uses one. 4-bit uses half a byte.

Batching affects waiting

More requests can improve throughput, but queued requests wait longer.
